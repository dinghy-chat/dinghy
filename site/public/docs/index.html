Start here

  1. Install Dinghy on a server. It takes one script.
  2. Add the chat to your website. It takes one tag.
  3. Learn the operator app, then invite your team and turn on alerts on your phone.

If something does not work, read Troubleshooting. If the server itself breaks, read the Runbooks.

Run the server

  • Self-hosting has the install, the settings, running behind your own proxy, backups, restore, upgrades and going back.
  • Runbooks say what to do when the disk is full, a service is down, mail fails or a release breaks.
  • Coolify and Dokploy says how the Compose file should fit those platforms. It is not tested on them yet.
  • Measurements has what one small server can do, and what we have not measured.
  • Phone push check tests alerts on real phones.
  • Changelog says what changed in each release, and what you must do.

Build on it

  • Architecture explains how the processes, tenant isolation, messages, live signals and jobs fit together.
  • API describes the HTTP API, and links its OpenAPI document at /v1/openapi.json.
