Questions

The short answers. For anything else, write to hello@dinghy.chat.

How much does it cost?

Free if you host it on your own server. $7 a month for each workspace if we host it, plus VAT or sales tax where it applies.

Is anything locked behind a plan?

No. The cloud and your own server run the same product, with every feature. On the cloud you pay for us to run it, not for features.

Will it slow down my site?

The tag loads a script under 3 KB gzipped. The chat itself loads when a visitor opens it.

Can an AI agent answer chats?

Yours can. Dinghy has no AI of its own, but your bot or agent connects through MCP or the API. Its replies wait as drafts for your team to send, unless you let it send directly.

Can I take my data with me?

Yes. Export a file at any time, and import it into your own server.

What do I need to host it myself?

A small Linux server and a domain. You need no third-party account or API key.
